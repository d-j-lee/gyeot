# 곁 — 아키텍처

## 1. 한 장 그림

```
 [Claude Code 세션들]──훅(exec, async)──┐
 [Codex 세션들]──────훅·notify─────────┤        gyeot-hook.exe
 [fsmap·AOK 하네스 log.jsonl]──tail────┤  (stdin → 400ms POST, 실패 시 스풀, 늘 exit 0)
                                       ▼
                         ┌──────────── gyeotd (127.0.0.1:47321) ────────────┐
                         │  gyeot-server: 인증·Host/Origin 검사·SSE·tail·스풀 │
                         │  gyeot-core:   정규화 → 엔진(항목·존재감·전달·제안) │  ← 결정적, 시계 없음, wasm 호환
                         │  events/*.jsonl (이벤트 소싱, 재생으로 복원)        │
                         └───────▲───────────────▲──────────────────▲─────────┘
                       SSE·REST  │               │ SSE·REST          │ 정적 파일
                                 │               │                   │
                 gyeot-channel.mjs (MCP, stdio)  │            face (웹 UI, Preact)
                 ↕ notifications/claude/channel  │            └─ 셸: Tauri 투명 오버레이
                 [실행 중인 Claude Code 세션]     └──────────── 브라우저·Edge 앱 창으로도 열림
```

## 2. 왜 이렇게 나눴나

이 세션 앞부분의 결론("코어는 Rust, 표면은 TS, 둘 사이는 프로토콜")을 그대로 적용했다.

| 부품 | 언어 | 이유 |
|---|---|---|
| `gyeot-core` | Rust | 판단은 결정적이어야 한다. 같은 이벤트를 넣으면 같은 결과가 나와야 재생·회귀 시험이 된다. 시계·파일·네트워크가 없어서 wasm으로 AOK 관제실(브라우저)에도 들어갈 수 있다. AOK 관제탑 v2 R3("인박스 규칙 코어를 Rust 한 벌로, 네이티브와 WASM에 같이")의 씨앗을 실제로 구현한 것이다 |
| `gyeot-server`·`gyeotd` | Rust | 오래 떠 있는 상주 프로세스는 메모리와 안정성이 중요하다. 실행 파일 하나로 배포된다 |
| `gyeot-hook` | Rust | 훅은 매 이벤트마다 뜨는 프로세스라서 시작 비용이 곧 에이전트 지연이다. exec 형식(`args`)은 Windows에서 진짜 `.exe`를 요구하므로 Git Bash·PowerShell을 거치지 않는다 |
| `gyeot-channel` | TypeScript | Claude Code channel은 MCP SDK(TS)가 공식 경로다. 파일 하나로 묶어 `node`로 띄운다 |
| `face` | TypeScript·Preact | UI는 웹 기술이 학습 데이터·생태계·IME에서 앞선다. 데몬이 직접 서빙하므로 셸 없이 브라우저로도 열린다 |
| `shell` | Rust·Tauri 2 | Windows에서는 WebView2(Chromium) 하나만 상대한다. 투명·항상 위·선택적 클릭 통과·트레이·전역 단축키만 맡는 얇은 껍데기다 |

버린 대안은 `docs/decisions.md`에 있다.

## 3. 프로세스와 수명

- **gyeotd**는 따로 산다. 로그인할 때 작업 스케줄러가 띄우거나, 셸이 처음 뜰 때 없으면 띄운다. 셸을 꺼도 이벤트는 계속 모인다.
- **gyeot-hook**은 훅 이벤트마다 잠깐 뜬다. `async: true`라 Claude Code는 기다리지 않는다.
- **gyeot-channel**은 Claude Code가 세션마다 띄운다(`.mcp.json` + 개발 채널 플래그). 데몬에 자기 `pid`·`ppid`·`cwd`를 등록하고 SSE로 메시지를 받는다. 데몬은 `ppid`를 훅의 `pid_hint`와 맞춰 어느 세션의 channel인지 안다. 못 맞추면 같은 `cwd`로 잇는다.
- **셸**은 UI만 담당한다. 서버를 내장하지 않는다.

## 4. 데이터 흐름

1. 훅 심이 원본 페이로드를 봉투(`payload`·`pid_hint`·`received_ms`)에 싸서 `POST /v1/ingest/<source>`.
2. 서버가 코어의 `normalize`로 정규화 이벤트를 만든다. 마스킹과 자르기가 여기서 끝난다. 프롬프트 본문과 트랜스크립트는 저장하지 않는다.
3. 이벤트를 `events/YYYY-MM-DD.jsonl`에 붙이고 엔진에 `apply`한다. 엔진은 효과(항목 갱신·삭제, 존재감, 전달, 제안, 세션)를 돌려준다.
4. 서버가 효과를 SSE로 얼굴에 흘린다. 1초마다 `tick(now)`가 시간 기반 규칙(멈춤 의심, 예산 충전, 미룸 만료, 대기 승격)을 돌린다.
5. 사람의 동작(처리·넘기기·미룸·집중)도 `user_action` 이벤트로 로그에 남는다. 그래서 다시 띄우면 로그 재생만으로 같은 상태가 된다.

## 5. 보안 모델

위협은 세 가지다. 같은 PC의 다른 웹 페이지, 같은 PC의 다른 사용자·프로세스, 그리고 channel을 통한 프롬프트 주입이다. 독립 검증(R1)에서 실제로 뚫린 경로를 막으면서 지금 모양이 됐다(`docs/contracts.md` §12).

- **주소**: `127.0.0.1`에만 묶는다. `Host`가 `127.0.0.1:<port>`·`localhost:<port>`가 아니거나 읽을 수 없으면 421(DNS 리바인딩). `Origin`은 같은 출처만 받는다(`null`·Tauri 출처 포함 거절). CORS 헤더는 내지 않는다.
- **토큰**: 32바이트 난수, 사용자 전용 파일. 훅 심·channel·셸·`gyeotd --open`만 쓴다. 쿼리 문자열로는 받지 않는다.
- **얼굴은 토큰을 모른다**: 페이지에 비밀을 싣지 않는다. 토큰을 가진 쪽이 120초짜리 일회용 부트 코드를 받아 창을 열면, 데몬이 HttpOnly·SameSite=Strict 세션 쿠키로 바꿔 준다. 디스크에는 세션 값의 해시만 남긴다. 그래서 다른 사용자가 `GET /`로 토큰을 얻을 수 없고, `?api=` 같은 주소 조작으로 비밀이 다른 출처에 새지 않는다.
- **얼굴 응답 헤더**: CSP(`connect-src 'self'`, `frame-ancestors 'none'`), `X-Frame-Options: DENY`. 다른 출처가 iframe으로 띄워 클릭을 속일 수 없다.
- **channel**: 듣는 포트를 열지 않고 데몬에 나가는 연결만 한다. 세션에 글을 넣는 길은 인증된 데몬 API 하나다. Claude의 답은 데몬이 그 channel에 발급한 `chat_id`로만 받는다.
- **승인은 사람의 일**: channel은 권한 중계를 선언하지 않는다. 승인 카드에는 승인 단추가 없다.
- **훅이 남기는 것**: 보내기 전에 정규화에 필요한 필드만 남기고 마스킹한다. 프롬프트 본문과 파일 내용은 스풀에도 남지 않는다. 스풀 파일은 사용자 전용 권한이다.
- **표시**: 모든 텍스트(Claude의 답, 훅 메시지)는 데이터로 다룬다. 얼굴은 HTML로 해석하지 않고 텍스트로만 그린다.

## 6. 저장

| 파일 | 내용 | 보관 |
|---|---|---|
| `events/YYYY-MM-DD.jsonl` | 정규화·마스킹된 이벤트와 사람 동작 | 14일(설정) |
| `learn.json` | 종류별 반응 집계, 받아들인 조정, 거절한 제안의 억제 기한 | 계속 |
| `spool/*.json` | 데몬이 꺼져 있을 때의 훅 요청 | 데몬이 비울 때까지 |
| `token` | API 토큰 | 계속 |
| `sessions.json` | 얼굴 세션 쿠키의 해시(값 원문 없음), 만료 시각 | 30일 |

SQLite 대신 JSONL을 고른 이유는 사용자 생태계의 다른 로그(fsmap·AOK 하네스)와 같은 모양으로 사람이 바로 읽을 수 있고, 재생이 곧 회귀 시험이 되기 때문이다.

## 7. AOK 관제실과의 관계

- 관제실은 claude.ai 아티팩트에서 클라우드 세션을 본다. 곁은 로컬 Windows 세션을 본다. 보는 대상이 다르다.
- 같은 kind 이름과 점수 식을 쓰므로, 사람에게는 하나의 "당신 차례"로 읽힌다.
- 다음 단계에서 `gyeot-core`를 wasm으로 빌드해 관제실 콘솔이 같은 점수·전달 규칙을 쓰게 할 수 있다. 그러면 규칙이 한 벌이 되고 시험도 한곳에 모인다(AOK R3). 로드맵 v0.2.
