## 실측할 것 (F 목록)

설계가 기대는 가정 가운데 이 컨테이너(Linux)에서 확인하지 못한 것이다. 처음 쓰는 주에 하나씩 확인하고, 결과는 `docs/field-notes.md`에 먼저 적는다.

| ID | 무엇을 | 어떻게 보면 되나 | 틀리면 |
|---|---|---|---|
| F1 | exec 형식 훅의 부모 프로세스가 `claude.exe`인가 | 세션 하나를 띄우고 얼굴의 대화 탭에서 그 세션이 "연결됨"으로 바로 잡히는지 본다 | `cwd`로 잇는 대체 경로가 동작한다. 같은 폴더에 세션 둘이면 최근 것으로 잇는다 |
| F2 | 개인 계정 Windows에서 개발 채널 플래그가 되는가 | `claude --dangerously-load-development-channels server:gyeot`로 띄우고 곁에서 말을 건다 | 대화 탭만 쓸 수 없다. 나머지 기능은 그대로다 |
| F3 | Codex 훅 입력 필드 | `~/.codex/hooks.json`에 곁을 걸고 `events/*.jsonl`에 `session`·`cwd`가 채워지는지 본다 | 정규화 표를 고친다 |
| F4 | Codex notify 인자 형식 | 턴이 끝날 때 `unread` 항목이 생기는지 본다 | 심의 인자 처리를 고친다 |
| F5 | WebView2 안에서 ko-KR 음성 목록 | 설정 탭의 음성 목록을 본다 | 음성 없이 소리만 낸다. Windows 설정 > 시간 및 언어 > 음성에서 한국어 음성을 받는다 |
| F6 | 투명 창의 선택적 클릭 통과 체감 | 아바타 밖을 클릭했을 때 뒤 창이 클릭되는지 본다 | 클릭 통과를 끄고 작은 창 모드로 쓴다 |
| F7 | Win+H 받아쓰기가 WebView2 입력란에서 되는가 | 대화 탭 입력란에서 Win+H | 브라우저 창 모드에서 쓴다 |
| F8 | 한글 IME 조합 중 Enter 처리 | 조합 중 Enter가 전송하지 않고 조합을 끝내는지 본다 | 조합 이벤트 처리를 고친다 |
